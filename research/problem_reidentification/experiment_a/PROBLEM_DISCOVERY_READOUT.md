# Experiment A：Silver 标注与问题发现

本轮使用实际模型 ID **`qwen-max`**，所有新判断均为 **`QWEN_MAX_SILVER`**。它们不能证明临床正确性，也不替代独立人工 Gold。最新覆盖、计数、token 与费用以 `results/silver_latest.json` 指向的聚合记录为准。

## 当前能够定位的问题

| 机制或问题 | 实际证据 | 可以得出的判断 | 仍需验证 |
|---|---|---|---|
| 日序与数值错配 | 原 30 条预测中有 1 条明确把其他日的睡眠值赋给缺测日；代码按原记录复查 | 该解释含可重复检查的局部证据错误 | 是否改变条件或整体适用性；是否跨窗口重复 |
| 条件引用接口不一致 | 1 条使用 condition_index 编号；按精确原请求索引还原 ID 后通过旧验证器 | 该格式问题已用确定性映射修复，标签与原文件不变 | 适用性判断及解释的语义正确性 |
| 验证器没有区分引用用途 | 一条解释明确排除无效 RHR，仍因数组含该位置而失败 | 不能把该失败当成使用无效生理证据；purpose 字段可支持更精确审计 | 更多案例的误报覆盖，以及修改原输出规范的控制实验 |
| 一般建议被收窄为排他条件 | 26 条来源审计中出现一般教育、可选背景与更强主张限制的混淆；11 条源审计仍带验证问题 | 原机器条件不能直接当成所有人都必须满足的 AND 前提 | 独立人工确认每条来源范围；稳定的总体错误频率 |
| 人群背景与精确个体年龄混淆 | 原解释及 Silver 轮次中同时出现已知成人队列和“无法确认成人”的理由 | 存在可检查的证据粒度/条件解释冲突 | 是否属于实际适用性错误，需审查准确主张与来源范围 |
| 强度分类与指南计量混淆 | 同一活动教育知识在 Silver A/B 分歧中，一侧要求已核验强度，另一侧依赖设备类别 | 标注模型自身也会改变条件角色，不能直接充当裁判 | 一般活动教育与精确指南达标判断应如何分别标注 |
| 变化检验与绝对状态混淆 | 原组合方法把基线/当前波动差异检验的解释用于是否存在绝对时间变异的判断 | 是值得复核的统计论证线索 | 不能仅凭两期差异不显著就断言日常规律；尚无修复对照 |

以上只有明确错日数值和格式试验获得了确定性软件核查。其他多为来源范围、解释或模型分歧线索。**没有证据表明这些问题是成熟方法无法解决的特定机制缺陷。**

## Silver 能做什么、不能做什么

首例是旧工程调试使用的共同窗口，最终两轮 10 条标注通过了结构/引用检查，但标签只有 4/5 一致。分歧涉及知识条件的范围解释；两轮各有自己的局限，一致也不证明正确。逐知识标签仅保存在私人队列。模型、Prompt 或候选顺序带来的变化不能直接归因于纵向推理能力。

扩展集在本轮预测前固定为其余 15 名参与者各最早一个窗口，共 75 个不同案例—知识对、两轮 150 条记录。已知的 E1 检索暴露没有排除，因此这里只称没有参与旧适用性 LLM 工程调试。扩展集的标签一致率和引用检查接受数见 [SILVER_LABEL_ANALYSIS.md](SILVER_LABEL_ANALYSIS.md)，拒绝/待复核记录仍保留。没有按模型错误挑选参与者或窗口。

新扩展集没有相应的新基线预测，所以当前六方法与 Silver 的直接比较仍只有旧共同窗口的五条知识。不能把 75 对 Silver 当成已完成六方法的多参与者比较，更不能把 150 次同家族模型标注当成 150 个独立案例。

## 修复证据与下一步

本轮实际验证了简单条件 ID 映射可以解决一个输出格式失败。统计补充、原基线 Prompt 调整和既有组件组合的医学适用性修复对照均未运行，不能宣称它们无效。早期为使 Silver JSON 正常输出而做的接口修正，也不是基线性能修复实验。

下一步最少需要独立人工确认关键来源条件及争议解释；区分普通健康教育、个体风险判断和更强的指南/诊断主张；复核 Silver 自身的引用与缺测处理错误；在预定参与者窗口上运行已有方法及少量明确的修复控制。只有这样才能判断是否存在跨案例、可重复的实质失败，以及是否被现有方法或简单组合解决。

原 C1/P1/A1 和人工 Gold 导入机制保持不变。没有训练模型或设计 M1/M2。原始健康片段、逐条判断理由、盲化映射和 API 凭据均不提交；完整私人复核队列保留了纵向证据、实际来源条件、基线预测、Silver 理由和未运行的修复项。

**目前的结论是：可以定位若干证据与接口问题，并发现范围解释分歧；Silver 仍不足以判定稳定的真实适用性错误，也不足以支持新算法必要性。**
