# B0 结果的独立审查边界

当前状态：`PREPARED_NOT_ANNOTATED`。本目录没有任何已完成的人类评审，软件测试数据不属于研究标注。

每个输出需由两名独立评审在隐藏方法、模型和约束名字的条件下检查；真正的分歧交由第三人裁决。先完成来源范围及数据语义校准，再查看方法间差异。不得让评审知道“哪个方法应该获胜”，不得用本轮 Qwen 输出或旧 `QWEN_MAX_SILVER` 充当裁判。

每个判断分开记录：

1. 输出结构是否完整，以及拒绝／缺失状态；不能补造未输出的候选。
2. 引用对应的 day、phase、metric、数值和质量是否正确。缺测引用若用于说明缺测，不等于无效生理证据。
3. 解释的主张是否由来源支持：一般教育、个体状态／风险、指南计量／诊断必须分开。原机器条件不是全部 AND 前提。
4. 在来源范围支持的前提下，解释能否支持实际选择；“听起来合理”不能代替证据。
5. 每个严格优先对是否确有候选之间的区分证据；允许 tie、不可比较和资料不足，不强迫唯一 Top-1。
6. 从共同初始输出到最终输出，发生的是纯解释变化、适用性变化、排序变化还是结构退化；“改变”本身不等于“修复”。

错误分类至少包含：引用格式、错日／错值、缺测／质量误用、来源范围越界、已知群体背景与未知个体属性混淆、绝对状态与变化检验混淆、候选相对理由不足、不可判定优先序、结构失败。分类不预设只由 S4 修复。若普通 Self-Refine、CRITIC 或简单组合已解决同类问题，应如实计入反证。

推荐准确率只有在相应优先关系已经被独立裁决、且评审没有参考被评估方法输出时才可计算。用于核查“这条解释是否有效”的输出审查，不自动成为独立排序 Gold。没有 Gold 的当前报告只包含行为、字面证据检查和候选顺序干预。

候选顺序反转不改变记录与来源内容，但修正类方法共享的 B1 初始化也随之重新生成，工具包使用原候选 canonical 顺序。因此它是整个管线的行为稳定性检查，不能单独隔离最终约束、不能被当作临床反事实有效性。需要后续固定初始状态、分别操纵证据与排序依据的独立干预，并由评审确认哪些关系应保持或改变。

预算对齐对照统一分配 6144 个最大输出 token、一次最终推荐修正，实际输入／输出 token、阶段数与费用另报。Self-Refine 分配给两次模型输出，CRITIC/ECR 分配给三次；输入重复、提示长度和实际生成量仍不同。这支持有限的预算上限控制，**不能完全排除 realized compute 或 Prompt 本身的影响**；不据它宣称独立新机制已被识别。
